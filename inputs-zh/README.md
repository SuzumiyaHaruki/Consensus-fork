# 提示词中文审阅稿

本目录用于中文审阅。当前 `protocol.md` 已合并协议说明与伪代码，`system.md` 单独描述目标系统；这些整理尚未同步到英文 `inputs/` 或 baseline。实验仍读取原有英文材料，不会自动加载本目录；待人工检查后再同步。

建议先阅读 [protocol.md](protocol.md)，再阅读 [system.md](system.md)（目标服务、运行时与成本要求）。protocol.md 的中文正文定义概念、前提和证据条件，英文伪代码集中表达状态转换、分支顺序和原子边界，说明文字解释原因，不逐步复述算法；本稿不再与英文原件逐段对应。其余角色提示仅同步了材料名称和数量。审计与复核中的 `<!-- continuation -->` 区分首次任务和同一会话的后续回合。

本文中的“接纳”指为请求正式分配协议实例；排队不等于接纳。“决定”指协议为实例选定值；“执行”指应用状态机实际处理命令。“退休”指经合法检查点替换后结束旧实例及其相关工作；不表示可以丢弃未完成的逻辑请求。“冷接收方”指尚未持有所需证据或快照的副本。“完整值”包括命令、检查点基准、依赖和序号等协议要求的全部字段。
