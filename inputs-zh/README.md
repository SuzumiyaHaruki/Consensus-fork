# 提示词中文审阅稿

本目录用于中文审阅。当前 `protocol.md` 以桌面 `mixed_epaxos_剪枝2.md` 的前八节为主体，合并 `mixed_epaxos_剪枝2_伪代码.md` 的对应算法；`system.md` 单独描述目标系统。已将审阅后的内容同步到英文 `inputs/` 和 `baseline/inputs/`；实验加载英文材料，不自动读取本目录。

建议先阅读 [protocol.md](protocol.md)，再阅读 [system.md](system.md)（目标服务、运行时与成本要求）。协议稿面向实现，正文只保留概念、前提和行为要求，英文伪代码按判断、更新和发送分行。证明推导、长例子和重复解释留在源文档，不作为生成输入；也不沿用历史实验的验证结论。审计与复核中的 `<!-- continuation -->` 区分首次任务和同一会话的后续回合。

本稿沿用已确认的客户端选择：请求号为 `(ClientID,RequestSeq)`，重试保留身份和载荷；已执行的重复请求返回 ALREADY_EXECUTED，不要求永久保留首次结果。这是对源文档“重复返回首次结果”要求的明确调整，正文、执行伪代码和 system.md 已一致修改。

“接纳”或“准入”指为请求正式分配实例并占槽；排队不等于接纳。“决定”固定实例的完整值，“执行”处理应用状态。依赖向量按分配实例的副本分组，每个副本至多一个编号；执行水位只用于跳过本地已执行的依赖，不能用于删除命令、投票或恢复记录。本版不包含旧稿的 epoch、检查点及退休流程。
