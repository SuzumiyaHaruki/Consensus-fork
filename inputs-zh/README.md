# 提示词中文审阅稿

本目录逐份对应 `../inputs/` 中的八份提示词，便于人工审阅。实验仍读取英文 `inputs/`，不会自动加载本目录；中文意见确认后，应同步修改英文原件。当前版本已分开给定设计、系统目标与通用工作方法。

建议先阅读 [AGENTS.md](AGENTS.md)（生成、修复共用的工程方法与工作边界）、[TASK.md](TASK.md)（生成任务）和 [system.md](system.md)（系统目标与交付要求，双方实验共用），再阅读 [protocol.md](protocol.md) 与 [pseudocode.md](pseudocode.md)（协议及其展开），最后阅读 [AUDIT.md](AUDIT.md)、[REPAIR.md](REPAIR.md)、[VERIFY.md](VERIFY.md)（审计、修复、独立复核）。文件名、章节顺序、协议符号、消息类型、命令、路径和 JSON 字段保留原名，便于与英文原件及代码核对。伪代码块保持原文；其前后说明、规则及表格均译成中文。审计与复核中的 `<!-- continuation -->` 是首次任务和同一会话续轮提示的分隔符。

本文中的“接纳”指为请求正式分配协议实例；排队不等于接纳。“决定”指协议为实例选定值；“执行”指应用状态机实际处理命令。“退休”指经合法检查点替换后结束旧实例及其相关工作；不表示可以丢弃未完成的逻辑请求。“冷接收方”指尚未持有所需证据或快照的副本。“完整值”包括命令、检查点基准、依赖和序号等协议要求的全部字段。
